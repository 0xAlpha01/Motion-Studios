# Motion Studios Abuja — Frontend

A polished React + Vite + Tailwind CSS website concept for Motion Studios, a Pilates and wellness studio in Wuse, Abuja.

## Run locally

```bash
npm install
npm run dev
```

## Build for deployment

```bash
npm run build
npm run preview
```

## Before sending it to the studio

- Confirm their current services, class timetable, prices and booking process.
- Replace any sample photography with approved images from Motion Studios.
- The call and WhatsApp buttons use the phone number visible on the Google business profile.
- Instagram links to `@motionstudios_ng`.
- The preview uses external Unsplash image URLs; use licensed/approved studio imagery for the final client build.

This is a frontend concept. It does not yet include a backend, live booking calendar, payments, or a content-management dashboard.
